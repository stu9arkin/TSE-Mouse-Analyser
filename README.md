# About
Development of a mouse video analyser. Created as part of our Team Software Engineering module using Agile development principles and a Kanban board to track development. We made use of image processing techniques such as segmentation via thresholding and connected component labeling to identify mice within a video sequence and perform some more advanced operations, such as attempting to identify the pose of a mouse in any given frame.

Written using Python, openCV2
